# Simple Interest Calculator

## Description
The Simple Interest Calculator is a simple application that calculates the interest amount based on the principal amount, annual interest rate, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal Amount
- Annual Interest Rate
- Time Period (in years)

## Example
Principal = 10000
Rate = 5%
Time = 2 years

Simple Interest = (10000 × 5 × 2) / 100

Output = 1000

## Technologies Used
- Programming Fundamentals
- Basic Arithmetic Operations

## Purpose
This project demonstrates basic mathematical calculations and programming concepts.
